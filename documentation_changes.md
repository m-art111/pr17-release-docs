# Изменения документации для выпуска 1.5.0

## 1. Лист замечаний к руководству оператора 1.4.2

Из руководства 1.4.2 в пакете известны только три поля: `version`, `max_attachments`, `network_timeout_advice`. Замечания относятся только к ним; остальной текст руководства в пакет не входит и не оценивается.

| № | Было (руководство 1.4.2) | Должно быть (основание) | Риск для пользователя | Правка | Расхождение |
|---|---|---|---|---|---|
| Д-01 | `max_attachments`: 5 | 3 — конфигурация кандидата и спецификация | Оператор прикладывает 4–5 файлов, получает отказ, не понимает причину | В разделе о вложениях: не более 3 файлов PDF/PNG, каждый до 5 000 000 байт, не пустой | Р-01 |
| Д-02 | «Нажимайте Отправить до появления номера» | После тайм-аута сначала проверить список — спецификация | Повторные нажатия, когда заявка уже сохранена; при изменённом тексте — конфликт; оператор не знает, создана ли заявка | Заменить совет порядком: сохранить текст → проверить список → один повтор → поддержка | Р-02 |
| Д-03 | Версия руководства 1.4.2 | 1.5.0 — версия выпуска | Инструкция к другой версии | Указать версию 1.5.0 в заголовке фрагмента | Р-03 |

Курс целиком не переписывается: ниже — только фрагмент, который нужен для этого выпуска.

## 2. Исправленный фрагмент руководства (версия 1.5.0)

> **Руководство оператора сервиса заявок. Версия 1.5.0.**
> Фрагмент заменяет в руководстве 1.4.2 раздел о вложениях и совет при отсутствии ответа.

### Вложения

К заявке можно приложить **не более 3 файлов**.

| Правило | Значение |
|---|---|
| Количество | от 0 до 3 |
| Тип | только PDF или PNG; тип проверяется по содержимому файла, а не по расширению |
| Размер | каждый файл не более 5 000 000 байт и не пустой |

Если файл не принят, текст заявки остаётся в форме — вводить его заново не нужно. Уберите лишние или неподходящие файлы и отправьте заявку ещё раз.

### Если после нажатия «Отправить» нет ответа

Заявка **могла сохраниться**, даже если номер не появился.

> ⚠️ Не нажимайте «Отправить» повторно, пока не проверите список заявок.

1. Скопируйте тему и описание заявки в текстовый файл или заметку.
2. Откройте список своих заявок и найдите заявку по теме.
3. **Заявка есть** — откройте её и запишите номер. Повторно отправлять не нужно.
4. **Заявки нет** — отправьте её **один раз**, не меняя текст.
5. Если ответа снова нет — больше не отправляйте. Ещё раз проверьте список. Если заявки по-прежнему нет, обратитесь в поддержку: сообщите время попыток, текст сообщения на экране и тему заявки.

## 3. Проверка фрагмента

| Правило спецификации | Отражено во фрагменте |
|---|---|
| От 0 до 3 файлов PDF/PNG | Да |
| Не более 5 000 000 байт включительно, пустой не принимается | Да |
| Тип проверяется по содержимому | Да |
| При отказе валидации текст остаётся в форме | Да |
| После тайм-аута сначала проверяется список | Да — шаги 1–3 до повтора |
| Повтор с тем же содержимым не создаёт дубль, с изменённым — конфликт | Да — «отправьте один раз, не меняя текст» |
