# Взаимная проверка пакета

| Поле | Значение |
|---|---|
| Режим | Самостоятельный проход по документам пакета |
| Что проверялось | Связность ссылок и цепочек между документами; соответствие пакету DOC-17 и спецификации |
| Ограничение | Пакет и проверку делал один участник, поэтому пропуски, очевидные новому читателю, могли остаться незамеченными. Согласование руководителем не требуется и не имитируется |

## 4. Проверка ссылок

Все ссылки на файлы во всех документах пакета проверены после исправлений: каждая ведёт на существующий файл. Ссылок на отсутствующие файлы нет.

## 5. Повторный проход после исправлений

Цепочка R_RESTORE: паспорт → матрица → протокол (П-1) → решение (действие 1, П-1, усл. 1) → регламент (усл. 1) → доказательство. Обрывов нет.
