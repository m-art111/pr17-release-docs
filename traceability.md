# Матрица трассировки

Кандидат 1.5.0-rc1, кейс DOC-17. Цепочка: требование → проверка → результат → доказательство → решение.
Формулировки требований — из [data/service_spec.md](data/service_spec.md); тесты и статусы — из [data/release_packet.json](data/release_packet.json). Статусы перенесены без изменений.

| Требование | Критерий (спецификация) | Проверка | Результат | Доказательство | Решение |
|---|---|---|---|---|---|
| **R_CREATE** | Заявка сохраняется и читается: один идентификатор, одна запись с автором и временем | T01 | `passed` | `synthetic-log-E01` — учебный маркер, не открываемый журнал | Принято в рамках кейса |
| **R_ACCESS** | Чужая заявка недоступна; доступ ограничивается сервером | T02 | `passed` | `synthetic-log-E02` — учебный маркер | Принято в рамках кейса |
| **R_IDEMPOTENCY** | Повтор с тем же `idempotency_key` и содержимым не создаёт дубль; изменённое содержимое — конфликт без новой записи | T03 | `passed` | `synthetic-log-E03` — учебный маркер | Принято в рамках кейса |
| **R_RESTORE** | RTO ≤ 20 мин, RPO ≤ 15 мин **и** данные после восстановления соответствуют контрольному набору (Р-05) | T04 | **`blocked`** | `restore-target-unavailable`; `last_restore_test`: `not_available_in_packet` | **Блокер выпуска** |
| **R_PERFORMANCE** | 20 одновременных операторов, 1000 заявок; успех ≥ 99 %; p95 ≤ 800 мс по всем попыткам, включая ошибки (Р-06) | T05 | **`not_run`** | Нет (`null`) | **Блокер выпуска** |

## Пояснения к незакрытым требованиям

### R_RESTORE — T04 `blocked`

| Поле | Значение |
|---|---|
| Чего не хватает | Целевой среды для восстановления (`restore-target-unavailable`) |
| Кто организует проверку | `test_owner` — student_tester (по роли в пакете). Предоставление целевой среды предлагается поручить `technical_executor` — student_engineer; в пакете это не закреплено |
| Что восстановить | Резервную копию B-1755 (база, вложения, конфигурация) |
| Что измерить | Время восстановления (RTO), возраст копии на момент сбоя (RPO), сверку данных с контрольным набором |
| Критерий | RTO ≤ 20 мин, RPO ≤ 15 мин, расхождений с контрольным набором нет |
| Ограничение | Подтверждение восстановления из другой работы сюда не переносится |

### R_PERFORMANCE — T05 `not_run`

| Поле | Значение |
|---|---|
| Кто проводит | `test_owner` — student_tester |
| Профиль | 20 одновременных учебных операторов, фиксированные 1000 заявок |
| Метод | Записать длительность **каждой** попытки, включая ошибочные. Доля успеха = успешные / все попытки. p95 = значение с рангом ceil(0,95·n) в наборе, отсортированном по возрастанию |
| Критерий | Доля успеха ≥ 99 % **и** p95 ≤ 800 мс |
| Не считается успехом | Пустой или заблокированный прогон |
| Доказательство | Набор длительностей, n, число успешных попыток, вычисленный p95 |
